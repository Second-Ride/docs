# 12V Schaltpläne

Die Schaltpläne zeigen die Elektrik deines Mopeds. Rot markiert ist, was sich durch das Umbaukit ändert: Das Kreuz steht für Komponenten, die entfernt werden können, der Pfeil für die Stellen, an denen +12V angeschlossen wird. Du musst keine Sorge haben, etwas falsch zu machen. Unser System hat einen Kurzschlussschutz, sodass lediglich das Licht solange nicht angeht, bis du den Fehler behoben hast.

Jeder Plan besteht aus mehreren Seiten. Das Titelfeld unten rechts nennt das Modell, für das die Seite gilt.
